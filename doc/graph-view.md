# Graph View — 知识图谱可视化

## 概述

Graph View 是 FolioNote 的拓扑感知知识图谱页面，基于 `@xyflow/react` 构建。它将笔记（entries）之间的引用、标签共享、来源共享关系以节点-边的形式可视化呈现，帮助用户发现笔记之间隐藏的关联。

**入口**：侧边栏 → Graph（原子图标）

**路由**：`/graph`

## 工具栏按钮功能

### 1. 搜索框（Search nodes...）

- 输入关键词，画布会自动聚焦到标题匹配的第一个节点
- 匹配节点会被选中并高亮
- 支持模糊匹配（大小写不敏感）

### 2. 标签筛选（Filter by tag）

- 下拉选择一个标签，图谱只展示打了该标签的笔记及它们之间的关系
- 选择 "All tags" 恢复全量展示
- 仅当你有已创建的标签时显示

### 3. Inferred edges（推断边）

- **开启**（默认高亮状态）：同时显示显式链接（ref / manual）和推断链接（shared-tag / shared-source）
- **关闭**：只显示显式链接（`/ref` 引用和手动建立的连线）
- 推断边用虚线表示，显式边用实线表示

**四种边类型的视觉区分**：

| 类型 | 含义 | 样式 |
|---|---|---|
| `ref` | 编辑器中通过 `/ref` 命令引用 | 实线 + 箭头，主题色 |
| `manual` | 在图谱中手动拖拽连线 | 实线，灰色 |
| `shared-tag` | 两个笔记共享相同标签（推断） | 短虚线，灰色 |
| `shared-source` | 两个笔记共享相同来源（推断） | 长虚线，灰色 |

### 4. Add link / Done（添加链接）

- 点击 "Add link" 进入**连线模式**（按钮变为 "Done"）
- 在连线模式下，从一个节点的底部连接点（source handle）拖拽到另一个节点的顶部连接点（target handle）
- 松手后自动创建一条 `manual` 类型的链接
- 如果两个节点之间已存在手动链接，会提示 "Link already exists"
- 点击 "Done" 退出连线模式

### 5. Fit view（适配视图）

- 一键将所有节点缩放到画布可见范围内
- 带 300ms 平滑动画

## 节点交互

### 单击节点

- 选中节点，右侧弹出 **Detail Panel**（详情面板）
- 面板显示：
  - 笔记标题
  - 状态标签（Starred / Pinned / Inbox）
  - 绑定的标签（彩色圆点 + 名称）
  - 引用关系：References to（该笔记引用了哪些） / Referenced by（哪些笔记引用了它）
  - "Open entry" 按钮跳转到笔记编辑页

### 双击节点

- 直接跳转到该笔记的编辑页面（`/entries/:id`）

### 拖拽节点

- 自由拖拽节点调整位置（位置目前不持久化）

---

## 画布控件

- **左下角 Controls**：缩放 +/- 按钮 和 fit view 按钮
- **右下角 MiniMap**：缩略导航地图，可拖拽/缩放
  - 金色节点 = 星标笔记
  - 灰色节点 = Inbox 笔记
  - 主题色节点 = 普通笔记

## 如何让笔记出现在图谱中

### 方式一：自动引用（推荐）

在编辑器中使用 `/ref` 命令引用另一条笔记：

1. 打开一条笔记进入编辑器
2. 输入 `/ref`（触发 slash command）
3. 选择要引用的目标笔记
4. 保存后，系统自动在 `entry_links` 表中创建一条 `ref` 类型的链接
5. 切换到 Graph View，两个笔记之间会出现带箭头的实线

> **原理**：每次保存笔记时，后端会从 ProseMirror JSON 内容中提取所有 `entry-ref` 链接标记，与数据库中的现有链接做 diff，自动插入新引用、删除已移除的引用。

### 方式二：手动连线

在 Graph View 中直接创建关联：

1. 点击工具栏的 "Add link" 按钮
2. 从节点 A 的底部小圆点拖拽到节点 B 的顶部小圆点
3. 松手后创建 `manual` 类型的链接
4. 点击 "Done" 退出连线模式

### 方式三：隐式关联（自动推断）

无需任何操作，系统会自动推断以下关系：

- **shared-tag**：两条笔记打了相同的标签 → 自动出现虚线连接
- **shared-source**：两条笔记来自相同的来源 → 自动出现虚线连接

这些推断边默认显示，可通过工具栏的 "Inferred edges" 按钮切换显隐。

## 数据模型

### `entry_links` 表

```text
id              : text (主键)
user_id         : text (用户 ID，级联删除)
source_entry_id : text (源笔记 ID，级联删除)
target_entry_id : text (目标笔记 ID，级联删除)
link_type       : text ('ref' | 'manual')
created_at      : timestamp
```

**约束**：`(source_entry_id, target_entry_id, link_type)` 唯一索引，防止重复链接。

### API 端点（oRPC）

| 过程 | 说明 |
|---|---|
| `graph.getGraph` | 获取全量图谱（支持 tagId / sourceId / includeInferred 筛选） |
| `graph.getNeighbors` | BFS 获取指定笔记的邻居（1-3 跳深度） |
| `graph.addManualLink` | 手动建立两个笔记之间的链接 |
| `graph.removeLink` | 删除一条链接 |
| `graph.getGraphStats` | 获取图谱统计（节点数、边数、孤立节点数、连接度 Top 5） |

## 快速上手指南

1. **确保有笔记**：至少创建 2 条以上的笔记
2. **建立关联**（三选一）：
   - 在编辑器中使用 `/ref` 引用其他笔记
   - 给多条笔记打相同标签
   - 在 Graph View 中手动拖拽连线
3. **打开 Graph View**：侧边栏点击 "Graph"
4. **探索图谱**：搜索、筛选、缩放、拖拽节点
5. **查看详情**：单击节点查看右侧面板
6. **跳转编辑**：双击节点或点击面板底部的 "Open entry"
